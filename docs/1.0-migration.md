# Migrating to the 1.x API

TommySlate 0.5.0 preserves every root attribute that existed in 0.4.1, but
`safe_slate.__all__` now contains only the proposed stable 1.x surface. This is
an import-boundary change, not a runtime decision change.

## Stable root imports

The seven stable entrypoints are `optimize_slate`, `optimize_replacements`,
`assess_serving_gates`, `guarded_rerank`, `guarded_candidate_pool_rerank`,
`audit_ope_readiness`, and `run_no_clobber_ope`. Their direct result types and
`ProposalLog` also remain available from `safe_slate`.

## Advanced support imports

Move advanced constructors and loaders to the submodule that owns them:

```python
from safe_slate.contract import create_ope_evaluation_contract
from safe_slate.input_manifest import create_input_manifest
from safe_slate.population_positivity import (
    create_population_positivity_evidence,
)
```

The complete transitive support list is machine-readable in
[`library.json`](../library.json). These APIs remain supported where they are
needed to construct stable inputs or consume stable results, but they are not
additional root entrypoints.

## Removal schedule

Legacy root attributes work throughout 0.5.x. They are removed from the root
namespace in 1.0.0rc1; the submodule imports continue to work. The RC and
1.0.0 API snapshots must match exactly.
